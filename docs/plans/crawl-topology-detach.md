## 1. 背景与问题

2026-11-10 用 books.toscrape.com 做 30 页实测：P3.5 的滚动、缩放、平移、+N 展开
全部生效，但 **L1 展开到约 29 个节点后标签完全不可读**。根因是拓扑区只有
`524×160` 像素（560×640 驾驶舱内的一个分区），缩放/平移解决"能动"，解决不了
"看得清"。

先生决策（2026-11-10）：拓扑区支持**左键按住直接拖出**为独立窗口查看，
看完点 ✕ **带动画收回**原驾驶舱。明确不要按钮触发、不要长按手势。

## 2. 目标与非目标

### 2.1 目标

1. 拓扑区内左键拖动 → 撕出为独立窗口（960×720、可自由拉伸、位置落在松手处）。
2. 独立窗口保留全部既有交互：Ctrl+滚轮缩放、右键/中键平移、双击右键复位、
   +N 展开、节点点击高亮；新增**「适应画布」**一键 fit-to-view。
3. 点独立窗 ✕ → **约 220ms 收回动画**（窗口飞回驾驶舱拓扑区并渐隐）→
   拓扑在驾驶舱原位置重绘。
4. 外弹/收回**视图状态无损迁移**（缩放/平移/展开/选中不重置）；跨窗口
   节点↔抽取行高亮联动保持。

### 2.2 非目标

- ❌ 拖拽回驾驶舱来 dock（收回只走 ✕ / 占位区点击）；
- ❌ 多份拓扑同时外弹（同一时刻最多一个独立窗）；
- ❌ 窗口位置/尺寸跨会话持久化（可选后续项）；
- ❌ 改动 Crawl、trace、布局纯函数的数据语义；
- ❌ GPU 级动画（Tk `after()` 逐帧插值是能力上限，见 §9）。

## 3. 手势契约（先生 2026-11-10 纠正后的最终版）

**判定只看两个维度：按下位置 + 拖动位移。没有时间阈值。**

| 区域 | 手势 | 行为 |
|---|---|---|
| 拓扑区内 | 左键单击（位移 <8px 即松开） | 节点 / +N 聚合 / 空白：既有高亮联动逻辑不变 |
| 拓扑区内 | **左键拖动（位移 ≥8px）** | **撕出拓扑**：幽灵预览跟随，松手生成独立窗 |
| 拓扑区外 | 左键拖动 | 移动整个驾驶舱（现状不变） |
| 拓扑区内 | 右键/中键拖动 | 平移拓扑（不变） |
| 拓扑区内 | Ctrl+滚轮 / 双击右键 | 缩放 / 复位（不变） |
| 任意 | Esc（撕出拖动中） | 取消撕出，幽灵销毁，无副作用 |

### 3.1 状态机（纯函数，可单测）

```
IDLE
  │ ButtonPress-1
  ├─ y 在拓扑矩形内 → PRESSED_IN_TOPO（记录起点）
  └─ 其他区域        → WINDOW_DRAG（既有移窗逻辑，不进入本状态机）

PRESSED_IN_TOPO
  │ B1-Motion，累计位移 ≥8px → ARMED（创建幽灵预览，开始跟随）
  │ ButtonRelease-1（未 ARMED）→ 走原 click 逻辑（节点/聚合/空白）
  └─ 右键按下/Ctrl 滚轮        → 取消本次跟踪，交给既有交互

ARMED
  │ B1-Motion → 幽灵跟随光标
  │ Esc       → IDLE（取消）
  └─ ButtonRelease-1 → 落点判定：
        · 光标在拓扑矩形外，或总位移 ≥80px → DETACH（在光标处生成独立窗）
        · 否则（拖了一小段又松手）         → IDLE（取消，不生成窗口）
```

要点：

- 8px 是"点击 vs 拖动"的消歧阈值，防止手抖误撕出；
- 80px / 出矩形是"真撕出 vs 拖了一下又放弃"的取消阈值；
- 节点/聚合的选中目前绑定在 ButtonPress 上，拖动起点落在节点上时会先触发一次
  高亮——**保留此行为**（无害：撕出后选中态随共享状态一起带走）。

## 4. 拖拽幽灵预览

- 无边框 Toplevel，`-alpha≈0.6`、`-topmost=True`、`overrideredirect(True)`；
- 内容：拓扑迷你轮廓（按当前可见节点画点，不重排布局）+ 一行
  `拓扑 · N 节点 · 松手生成独立窗口`；
- 尺寸约 200×120，光标位于其中心；`after(16ms)` 或 B1-Motion 直接驱动跟随；
- **不抢键盘焦点**（不调用 `focus_set`），不打断终端输入；
- 取消/落点后立即销毁。

## 5. 独立窗口

| 项 | 规格 |
|---|---|
| 尺寸 | 默认 **960×720**，`resizable(True, True)`，用户可自由拉伸 |
| 位置 | 松手光标处（窗口中心对齐光标，越界时钳制到屏幕内） |
| 外观 | 与驾驶舱同一 HUD 语言：无边框、深色、角标；顶部标题 `CRAWL TOPOLOGY // 拓扑独立窗` |
| 控件 | 右上 **✕ 收回**；标题栏左侧 **「适应画布」**；底部操作提示行 |
| 画布 | 随窗口拉伸重排（布局纯函数按新 width/height 重算） |
| 交互 | Ctrl+滚轮缩放、右键/中键平移、双击右键复位、+N 展开、节点点击高亮 |
| 适应画布 | 一键把整图缩放+平移到恰好铺满当前画布（含全部可见节点与 +N，留 5% 边距）；**撕出落点即自动执行**（2026-11-10 先生实测后调整：不再依赖手动点击） |

独立窗内**不提供** URL 清单与抽取表（那些留在驾驶舱）；点节点时驾驶舱
对应抽取行照常高亮（§7）。

## 6. 收回动画

点独立窗 ✕（或点驾驶舱占位区「点击收回」）触发：

1. 取独立窗当前屏幕矩形 `R0`，取驾驶舱拓扑区**实时**屏幕矩形 `R1`
   （`winfo_rootx/y` + 区域常量，驾驶舱被移动过也能准确飞回）；
2. **220ms、14 帧（after 16ms）、ease-out 三次曲线** `e(t)=1-(1-t)³`：
   - `rect(t) = R0 + (R1-R0)·e(t)`（x/y/w/h 四项插值）；
   - `alpha(t) = 1 - 0.8·e(t)`（1.0 → 0.2 渐隐，避免闪没）；
3. 末帧：销毁独立窗 → 驾驶舱拓扑区按共享状态重绘 → 动画期间忽略重复 ✕；
4. 动画插值做成纯函数 `interpolate_rect(r0, r1, t)` / `alpha_at(t)`，可单测。

若动画期间 Tk 报窗口已销毁（极端情况用户强杀），直接落到末帧逻辑，不抛异常。

## 7. 共享状态与跨窗联动

抽取 `TopoViewState`（普通数据类）：

```python
scale: float = 1.0
pan_x: float = 0.0
pan_y: float = 0.0
expanded_layers: dict[int, int]  # +N 展开
selected_url: str | None         # 节点↔抽取行选中
```

- `CrawlWindow`（驾驶舱）与 `TopoDetachedWindow`（独立窗）持有**同一个实例**，
  外弹/收回零迁移成本；
- 驾驶舱的 `_selected_url` 改为读写共享状态，独立窗点节点 → 驾驶舱抽取行
  高亮；驾驶舱点抽取行 → 独立窗对应节点亮环（双方都重绘）；
- 新轮次（run_id 变化）`reset_interaction()` 重置共享状态，两窗同步。

## 8. 生命周期与模块规划

### 8.1 生命周期（挂在 CrawlManager 上）

- `sync()`：有数据时，已外弹则独立窗重绘，驾驶舱画占位+统计；
- `hide_all()` / `show_all()`：独立窗随驾驶舱同步隐藏/显示；
- `detach()`：先销毁幽灵与独立窗（**若正在拖拽/动画中，直接落到终态**），
  再销毁驾驶舱；沿用"先置空 Tk 引用再 destroy"防跨线程 GC 约束；
- 置顶让位：终端前台时独立窗同样 `set_topmost(False)`；
- 撕出中 task 结束：幽灵照常销毁，已生成的独立窗保留（与"结束保留"策略一致）。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 手抖误撕出 | 8px 武装阈值 + 80px/出矩形落点阈值 + Esc 取消 |
| 撕出与节点点击冲突 | 单击不进入 ARMED，原 click 逻辑不变；拖动起点在节点上的预先高亮无害保留 |
| 动画不流畅 | 220ms/14 帧是 Tk 上限内的"够流畅"；插值纯函数保证轨迹正确，接受非 GPU 丝滑度 |
| 两窗重绘成本 | 60 节点级数据量可忽略；render 幂等 |
| 动画/拖拽中窗口被销毁 | 所有 after 回调先查窗口存活，异常落终态，不抛给主流程 |
| 幽灵抢焦点 | 不 focus_set；仅 topmost 展示 |

## 10. 验收清单

自动化（纯函数 + FakeCanvas）：

- 手势：区内外分流、8px 武装、单击不触发撕出、Esc 取消；
- 落点：出矩形/≥80px 撕出、小区位移取消；
- 动画：插值端点精确、单调、ease-out 曲线、alpha 范围；
- 共享状态：外弹/收回后 scale/pan/expanded/selected 不变；
- fit-to-view：全部可见节点落入画布且边距正确；
- 全量 `pytest tests -q` 全绿。

人工走查：

1. 拓扑区按住拖出 → 幽灵跟随 → 松手生成 960×720 独立窗；
2. 独立窗拉伸、缩放、平移、fit、+N、点节点 → 驾驶舱抽取行高亮；
3. 点 ✕ → 动画飞回 → 驾驶舱拓扑原位置恢复且视图状态未重置；
4. 拓扑区外拖动仍移动驾驶舱；单击节点仍是高亮；
5. 撕出中按 Esc / 拖 8px 内松手 → 无副作用。
