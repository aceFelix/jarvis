## 三、实时聊天窗口架构

### 父子进程模型

```
父进程（daemon 或 CLI）
    │
    ├─ RealtimeTalkWindow (控制器)
    │   ├─ standalone=True  → 子进程自己跑 RealtimeTalk
    │   └─ standalone=False → 父进程跑 RealtimeTalk，子进程只渲染
    │
    └─ multiprocessing.spawn → 子进程
            ├─ _FrontendWindow (pywebview 主线程)
            ├─ JSBridge (Python ↔ JS 桥接)
            └─ RealtimeTalk 线程（standalone=True 时）
```

**为什么用 multiprocessing**：
- pywebview 必须在主线程运行
- daemon 主线程已被托盘占用
- 子进程主线程跑 webview，通过队列通信

### RealtimeTalkWindow 单例管理

[window.py](file:///e:/2.MyProjects/MyAgentChat/J.A.R.V.I.S/jarvis/agent/ui/realtime_window/window.py)：

```python
class RealtimeTalkWindow:
    """父进程中的实时聊天窗口控制器。

    管理一个子进程中的 webview 窗口。同一父进程生命周期内
    只维护一个子进程/窗口实例。
    """
    def __init__(self, on_close=None, *, standalone=True):
        self._config = {}
        self._standalone = standalone
        ...

    def set_config(self, config):
        """设置 RealtimeTalk 配置（api_key/model/voice/ws_url）。"""
        self._config = config

    def show(self):
        """启动子进程显示窗口。"""

    def is_open(self) -> bool:
        """窗口是否仍在运行。"""
```

**单例行为**：
- daemon 生命周期内只维护一个窗口
- 重复点击托盘"实时聊天"唤起已有窗口
- 窗口随 daemon 退出而销毁

### standalone 模式

| 模式 | standalone=True | standalone=False |
|---|---|---|
| **用途** | CLI `/talk` 独立入口 | daemon 嵌入 |
| **RealtimeTalk 运行在** | 子进程 | 父进程 |
| **子进程职责** | 渲染 UI + 跑 RealtimeTalk | 只渲染 UI |
| **配置传递** | `set_config()` 传给子进程 | 父进程直接用 |

**为什么 standalone=True**：CLI `/talk` 时父进程是 REPL，不能阻塞。子进程自己跑完整实时对话，父进程只等窗口关闭。

### JSBridge 桥接

[process.py](file:///e:/2.MyProjects/MyAgentChat/J.A.R.V.I.S/jarvis/agent/ui/realtime_window/process.py) 的 `JSBridge`：

```python
class JSBridge:
    """暴露给前端 JS 调用的 Python API。"""

    def poll_events(self) -> list[dict]:
        """JS 轮询获取 Python 端产生的事件。"""
        # 返回 [volume/status/transcript/...] 事件列表

    def close_session(self) -> None:
        """用户点击"结束"按钮 → 关闭窗口。"""
        self._window.destroy()
```

**通信方向**：
- Python → JS：通过 `event_queue` → `poll_events()` 轮询
- JS → Python：通过 `pywebview.api.*` 调用

### WebviewRealtimeTalkUI

[bridge.py](file:///e:/2.MyProjects/MyAgentChat/J.A.R.V.I.S/jarvis/agent/ui/realtime_window/bridge.py) 实现 [RealtimeTalkUI](file:///e:/2.MyProjects/MyAgentChat/J.A.R.V.I.S/jarvis/agent/core/context.py#L41-L77)：

```python
class WebviewRealtimeTalkUI:
    def on_status(self, status): self._window.emit("status", status)
    def on_volume(self, level): self._window.emit("volume", level)
    def on_user_speaking(self, s): self._window.emit("user_speaking", s)
    def on_ai_speaking(self, s): self._window.emit("ai_speaking", s)
    def on_user_transcript(self, text): self._window.emit("user_transcript", text)
    def on_ai_transcript(self, text): self._window.emit("ai_transcript", text)
```

通过 `emit()` 把事件放入队列，前端 `poll_events()` 轮询获取。

## 六、设计取舍

| 决策 | 选择 | 理由 |
|---|---|---|
| 终端 UI | Rich + prompt_toolkit | 美观 + 补全 |
| 窗口 UI | pywebview + Canvas | 跨平台 + 动画 |
| 父子进程 | multiprocessing | pywebview 要主线程 |
| 通信 | 队列 + 轮询 | 简单可靠 |
| 单例窗口 | 是 | 避免重复占用麦克风 |
| 启动动画 | 可跳过 | 非TTY会乱码 |
