## 二、三层配置合并

### 优先级（后者覆盖前者）

```
1. 内置默认值 (Settings dataclass)
       ▼
2. configs/settings.toml (项目级，随仓库分发)
       ▼
3. ~/.jarvis/settings.toml (用户级，自动创建)
       ▼
4. 环境变量 (JARVIS_* 前缀，由 env.py 处理)
       ▼
5. API Key 系统 keyring (仅 api_key，env.py 兜底)
       ▼
6. CLI 参数 (main.py 处理)
```

```python
    ...
```

**为什么三层**：
- 项目级：随仓库分发，提供默认值
- 用户级：个人偏好，持久化（如 last_model、custom_models）
- 环境变量：CI/CD、容器化部署

### 上下文压缩

```python
context_compaction: bool = True
context_window: int = 128000  # 模型窗口大小（token），换模型时同步修改，勿设 0
compact_ratio: float = 0.5    # 触发比例（占窗口百分比）
compact_refreeze_growth: float = 1.25  # 防抖：冻结后总量增长不足此倍数不重复压缩
compact_max_output_tokens: int = 2048  # 压缩摘要请求的输出 token 上限
tool_result_keep_recent: int = 4  # 工具结果折叠时保留最近 N 条完整输出
```

自动压缩触发条件（唯一机制，比例模式）：

- 总 token（冻结摘要 + 活跃窗口 + system prompt）≥ `context_window × compact_ratio` 时才触发；未超比例绝不压缩，用满窗口前半程。
- 附带防抖：总量较上次冻结后增长不足 `compact_refreeze_growth` 倍不重复压缩，避免窗口配置过小时每轮白压。
- 旧的 `compaction_threshold`（绝对阈值）与 `keep_recent_messages`（可配保留条数）已移除：保留条数固定为内部默认 6。


环境变量都未命中时，`env.py` 回退到 [keyring_store.py](file:///e:/2.MyProjects/MyAgentChat/J.A.R.V.I.S/jarvis/agent/config/keyring_store.py) 从系统 keyring 读取（S-01）。

## 七、敏感字段脱敏（S-03）

[utils/mask.py](file:///e:/2.MyProjects/MyAgentChat/J.A.R.V.I.S/jarvis/agent/utils/mask.py) 统一脱敏展示场景：

- `mask_key()`：API Key 只显示首 4 + 尾 4 位（`sk-12...34`）
- `mask_url_key()`：URL 查询参数中的 `api_key=/sk-` 脱敏
- `mask_error_message()`：错误消息中的 Bearer token / sk- 密钥 / URL key 全部脱敏

应用于：`/config show`、`jarvis doctor`、LLM 错误提示（errors.py）等所有展示场景。

## 八、last_model 持久化

### 为什么持久化

用户切换模型后，下次启动自动恢复上次选择。

### 实现

- `last_model` 存在 `~/.jarvis/settings.toml` 顶层
- 启动时若 `last_model` 存在，覆盖 `model`
- 切换模型时调用 `save_last_model()` 持久化

### 关联字段

切换模型时一起持久化：
- `last_model`
- `provider` / `api_format` / `base_url` / `api_key`
- `default_provider` / `default_api_format` / `default_base_url` / `default_api_key`（原始值）

**为什么存 default_*：切回内置模型时用这些值重建 provider，避免停留在自定义模型配置上。

## 十二、配置覆盖工具与引导命令

### with_overrides

```python
def with_overrides(self, **kwargs) -> Settings:
    """返回用 kwargs 覆盖部分字段的新 Settings（None 值不覆盖）。"""
    data = {k: v for k, v in kwargs.items() if v is not None}
    return Settings(**{**self.__dict__, **data})
```

用于子代理等场景创建配置变体。

### jarvis init（U-01）

`jarvis init` 交互式引导首次配置：选厂商 → 输入 Key → 测试连接 → 保存到 `~/.jarvis/settings.toml`。
实现位于 [commands/handlers/init_command.py](file:///e:/2.MyProjects/MyAgentChat/J.A.R.V.I.S/jarvis/agent/commands/handlers/init_command.py)。

## 十三、设计取舍

| 决策 | 选择 | 理由 |
|---|---|---|
| 配置格式 | TOML | Python 3.11+ 内置支持 |
| 合并层级 | 三层 + env + keyring | 灵活覆盖 |
| 持久化 | 用户级文件 | 跨会话保持 |
| 环境变量 | env.py 独立模块（A-03） | 职责单一，易维护 |
| 模型持久化 | model_registry.py 独立模块 | 与加载逻辑解耦 |
| API Key | keyring 加密存储（S-01） | 减少明文暴露面 |
| 敏感字段 | mask.py 统一脱敏（S-03） | 展示场景一致安全 |
| last_model | 顶层存储 | 早期存 [llm] 段导致不加载 |
| custom_models | [llm.custom_models] | 结构化存储 |
