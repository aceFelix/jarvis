## 设计哲学

J.A.R.V.I.S 借鉴了 Claude Code 的核心设计思想：

1. **工具驱动**：AI 的能力来自工具调用，工具是带元数据+权限+执行+渲染的对象
2. **fail-closed 安全**：所有安全属性默认为"危险"侧，工具必须显式声明自己安全
3. **流式优先**：LLM 响应、TTS、STT 都走流式，低延迟体验
4. **上下文自管理**：LayeredContext 冻结前缀 + 滑动窗口，自动压缩旧消息，缓存友好
5. **按需加载**：工具 deferred 延迟加载 + Skill 三层按需加载（摘要/触发词/LoadSkill），减少 token 消耗
6. **可扩展架构**：Tool/MCP/Skill/Plugin/Hook 多层扩展点，新增 skill 无需改代码
7. **协议抽象**：UIProtocol/LLMProvider/RealtimeTalkUI 等协议解耦实现
8. **跨平台适配**：System Prompt 动态平台规范、热键/沙箱/GUI 多平台原生实现
9. **稳定性优先**：MCP 分步超时、错误自愈、网络重试、故障转移，保证长会话稳定
