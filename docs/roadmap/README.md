## 新增一篇时

1. **命名**：`PLAN-<主题>.md`；已完成的阶段方案保留原名，不改成 `-done`。
2. **头部**：写清状态（已交付 / 进行中 / 暂缓 / 历史）、优先级与立论数据；
3. **只写取舍**：目标、成本账、被否决的方案与理由；落地细节放 `plans/`。
4. **归档**：放进对应子目录，并在该子目录 `README.md` 补一行；
   没有合适分类就新建目录，并在本文「分类总览」加一行。
5. **跑链接门**：`python scripts/check_md_links.py`（0 死链、0 未入库链接）。
