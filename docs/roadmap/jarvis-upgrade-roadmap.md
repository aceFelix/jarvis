# J.A.R.V.I.S 升级路线图

> 目标：从"好用的本地 AI 助手"进化为"真正随叫随到、主动陪伴、能帮我操作一切的智能助手"。

---

### 一句话定位

J.A.R.V.I.S 目前已经是一个**功能完整的 Windows 个人智能体**：61 内置工具 + 71 CLI-Anything harness，双模语音（STT+TTS 循环 + 全双工实时 + WebRTC AEC3 回声消除 + Function Calling 工具调用），五层权限，常驻后台，13 个能力维度中 9 个达到 ⭐⭐⭐⭐ 生产可用、3 个达到 ⭐⭐⭐ 稳定可靠。但距离"随叫随到、主动陪伴、包办一切"的贾维斯形态，还需要**跨平台移动端、主动感知、自主决策、跨应用深度自动化、情感记忆、多端协同、离线能力**等关键跃迁。

## 二、目标定义

### 2.1 随叫随到

- 7×24 小时低功耗常驻后台
- 多种唤醒方式：语音唤醒词、全局热键、摄像头视觉唤醒、系统事件触发
- 秒级响应，无需手动打开终端
- 断网/弱网环境下仍有基础离线能力

### 2.2 主动陪伴

- 能主动观察用户状态（在电脑前、离开、疲惫、专注）
- 能根据日程、习惯、系统状态主动提醒或建议
- 记住用户长期偏好、项目背景、沟通风格
- 不只是回答问题，而是像助手一样"想到前面"

### 2.3 帮我操作一切

- 看懂屏幕并执行复杂 GUI 工作流
- 能跨多个应用完成端到端任务（如"帮我整理这周发票并邮件发给财务"）
- 能自动化重复性工作并学习新流程
- 能操作邮件、日历、聊天软件、云服务等系统级能力
- 能连接手机、平板、智能家居等设备

## 三、升级路线图

### Phase 1：近期（1-3 个月）—— 核心体验补齐

**目标**：让现有能力更稳定、更自然、更易用。

| 编号 | 能力 | 说明 | 优先级 |
|---|---|---|---|
| P1-1 | **语音唤醒词** | 不依赖热键，说"贾维斯"即可唤醒，类似智能音箱（已实现） | 高 |
| P1-2 | **更快的热键响应** | 全局热键从唤起窗口到可输入控制在 500ms 内（已完成：Windows 原生 RegisterHotKey + 窗口复用 + warm 进程 + --quick 快速启动） | 高（已完成） |
| P1-3 | **实时语音稳定性** | 提升 `/talk` 网络抖动下的重连、打断、静音检测（已完成：自动重连 + 客户端 VAD 兜底 + 心跳保活 + WebRTC AEC3 回声消除 + smart_turn 语义轮次检测 + Function Calling 工具调用） | 高（已完成） |
| P1-4 | **GUI 自动化增强** | 支持拖拽、右键菜单、多窗口协调、等待元素出现 | 高（已完成） |
| P1-5 | **视觉理解增强** | 屏幕截图 + 图标识别，让 AI 能"看懂"当前界面 | 高（VisualClick 已覆盖图标识别） |
| P1-6 | **配置可视化 UI** | 用 Web/桌面界面管理模型、API Key、权限、插件，降低使用门槛 | 中 |
| P1-7 | **一键安装包** | 提供 Windows `.exe` / macOS `.app` / Linux `.AppImage` | 中 |
| P1-8 | **错误自愈** | 工具调用失败时自动重试、降级、询问用户 | 中 |
| P1-9 | **实时语音 Function Calling** | `/talk` 实时聊天中模型可自主调用工具获取实时信息（已完成：内置时间工具 + ToolRegistry 全部工具接入 + 高风险操作语音询问用户确认 + 结果截断防播报过长） | 高（已完成） |

### Phase 2：中期（3-6 个月）—— 主动感知与自动化

**目标**：从"响应指令"进化为"主动服务"。

| 编号 | 能力 | 说明 | 优先级 |
|---|---|---|---|
| P2-1 | **用户在场感知** | 通过摄像头/鼠标键盘活动判断用户是否在电脑前 | 高 |

| P2-4 | **工作流编排** | 用户演示一遍操作，AI 学习并自动复现（RPA 模式） | 高 |
| P2-5 | **邮件/日历/消息集成** | 读写邮件、管理日历、发送消息通知 | 高 |

| P2-7 | **习惯学习** | 记录用户常用命令、工作目录、偏好模型，越用越顺手 | 中 |
| P2-8 | **智能待办** | 从对话中自动提取任务，持续跟踪直到完成 | 中 |

### Phase 3：远期（6-12 个月）—— 智能化与跨端协同

**目标**：从"电脑助手"进化为"个人智能中枢"。

| 编号 | 能力 | 说明 | 优先级 |
|---|---|---|---|
| P3-1 | **跨设备协同** | 手机/平板/电脑/智能家居统一接入，状态同步（进行中：终端输入 `/connect-phone` 显示二维码，手机扫码后通过 Web PWA 与 JARVIS 对话，共享会话 + PLAN 权限隔离 + Token 认证） | 高 |

### Phase 4：愿景（12 个月+）—— 真正的 AI 伙伴

**目标**：像《钢铁侠》里的贾维斯一样，成为用户不可分割的一部分。

| 编号 | 能力 | 说明 |
|---|---|---|
| P4-1 | **多模态全时感知** | 同时理解语音、视觉、屏幕、键盘、日历、位置、生物节律 |
| P4-2 | **预测性服务** | 在用户开口前就知道需要什么，提前准备好 |
| P4-3 | **自主数字分身** | 能代表用户处理邮件、会议、日程、代码审查等日常事务 |
| P4-4 | **可信自主执行** | 在明确授权范围内自动完成复杂任务，无需逐次确认 |
| P4-5 | **持续学习进化** | 从每次交互中学习，自动更新 Skill、记忆、工作流 |

## 四、关键技术挑战

| 挑战 | 说明 | 解决思路 |
|---|---|---|
| **低功耗常驻** | 7×24 运行不能占用大量 CPU/内存 | 分层唤醒：轻量级监听 + 需要时再启动完整 Agent |
| **隐私保护** | 摄像头、麦克风、屏幕常驻引发隐私顾虑 | 本地优先、明确指示灯/状态、用户可控开关、敏感操作确认 |
| **跨应用自动化可靠性** | GUI 自动化容易受界面变化影响 | 结合视觉 + 元素定位 + 可学习的工作流回放 |
| **主动与打扰的平衡** | 过于主动会打扰用户 | 用户可配置主动等级，AI 学习用户接受度 |
| **多设备协同** | 不同设备间状态同步和任务接力 | 本地优先的端到端加密同步协议 |
| **离线能力** | 没网时仍需基础功能 | 本地模型 + 本地语音 + 本地工具执行 |

## 五、建议的下一步

按照**高 ROI、低风险**的原则，结合当前 13 维度能力短板（多 Agent 协作 ⭐⭐、主动感知 ⭐⭐、Plugin 市场 ⭐⭐、工具执行 ⭐⭐⭐、常驻后台 ⭐⭐⭐），建议按以下顺序推进：

### 第一波：补短板（夯实已有能力的薄弱环节）

1. **多 Agent 协作增强**（维度 11，⭐⭐ → ⭐⭐⭐）：完善子代理任务委派、团队编排、邮箱协议，让"复杂任务拆分"真正可用。
2. **Plugin 市场完善**（维度 12，⭐⭐ → ⭐⭐⭐）：补齐插件搜索/安装/卸载/版本管理/依赖解析，让生态能自增长。
3. **工具执行稳定性**（维度 5，⭐⭐⭐ → ⭐⭐⭐⭐）：P1-8 错误自愈 + 工具调用重试/降级/超时控制。

### 第二波：核心体验跃迁（让"随叫随到"先可用）

4. **P1-1 语音唤醒词** + **P1-2 热键响应优化（已完成）**：从"手动唤起"到"语音随叫"。
5. **P1-3 实时语音稳定性（已完成）**：网络抖动重连、打断、静音检测，让 `/talk` 生产可用。

### 第三波：操作能力跃迁（让"操作一切"更可靠）

6. **P1-4 GUI 自动化增强（已完成）** + **P1-5 视觉理解增强**：拖拽/右键菜单/多窗口协调/等待元素 + 图标识别。
7. **P1-6 配置可视化 UI**：降低使用门槛，让非技术用户也能用。

### 第四波：从响应到主动（让"主动陪伴"萌芽）

8. **P2-1 用户在场感知** + **P2-3 主动提醒系统**：摄像头/键鼠活动判断在场 + 日历/截止日期/系统状态主动提醒。
9. **P2-4 工作流编排（RPA 模式）**：用户演示一遍 → AI 学习复现，这是从"助手"到"自动化"的关键跃迁。

### 第五波：长期基础（为远期愿景打底）

10. **P3-2 本地化大模型**：支持本地 LLM/VLM（Qwen、Llama、Phi），保护隐私 + 离线能力。
11. **P3-1 跨设备协同**：手机/平板/电脑/智能家居统一接入，状态同步。
12. **P3-8 安全沙箱执行**：高风险操作隔离环境运行，配合 YOLO 模式实现可信自主执行。

---

## 六、结论

J.A.R.V.I.S 已经完成了从 0 到 1 的构建，覆盖了 13 个能力维度，其中 9 个达到生产可用（⭐⭐⭐⭐）。下一阶段的重点不是横向铺更多功能，而是：

- **补短板**：把 ⭐⭐ 的多 Agent 协作打磨到 ⭐⭐⭐，主动感知从 ⭐⭐⭐ 继续向 ⭐⭐⭐⭐ 迈进（用户状态感知、习惯学习）
- **让现有能力更稳定、更自然**：错误自愈、语音唤醒、GUI 自动化
- **从被动响应转向主动感知**：用户在场感知 + 主动提醒 + 习惯学习
- **从单点工具转向端到端自动化**：工作流编排 RPA 模式 + 跨应用集成
- **从电脑助手转向个人智能中枢**：本地化模型 + 跨设备协同 + 可信自主执行

这条路线上，最大的技术挑战不是某一项功能，而是**如何在常驻、主动、自动化的同时，保持低资源占用、高隐私安全和用户可控性**。
