# 语音识别概述

> 百炼语音识别支持实时音频和录音文件转写，提供多语言与方言、热词与上下文、文本润色、说话人分离等能力。

<meta property="og:title" content="语音识别概述" />

## 功能介绍 <span id="asr-capabilities" />

语音识别将音视频中的语音转换为文本，可用于语音输入、实时字幕、会议记录和通话分析等场景。百炼支持持续输入音频的实时识别，以及提交完整音频文件的非实时识别；不同模型支持的语言、方言和增强能力有所不同。

## 识别效果与结果 <span id="asr-results-and-quality" />

选定模型后，可根据业务需要改善特定词汇的识别、文本可读性及结构化结果。具体配置方法参见[实时语音识别](/zh/model-studio/real-time-speech-recognition-user-guide#rt03_advanced_h2)或[非实时语音识别](/zh/model-studio/non-realtime-speech-recognition-user-guide#nrt03_advanced_h2)。

- **热词与上下文**：<span id="b1a2c3d4e5f51" /> <span id="b1a2c3d4e5f50" /> 热词提供人名、品牌名等词汇的目标写法；上下文补充前几轮对话及业务背景。使用方法、支持范围和调优参见[提升识别准确率](/zh/model-studio/improve-asr-accuracy)。

- **文本润色**：<span id="asr-text-refinement" /> 整理口语中的语气词、重复和自我纠正。qwen-audio-3.1-asr-flash-message 和 qwen-audio-3.1-asr-flash 支持原生文本润色。

- **保留方言表达**：<span id="asr-dialect-expression" /> qwen-audio-3.1-asr-flash-streaming、qwen-audio-3.1-asr-flash-message、qwen-audio-3.1-asr-flash、qwen-audio-3.1-asr-flash-filetrans 支持保留方言特有表达。识别某种方言与保留其文本表达是不同的能力。

- **说话人分离**：<span id="b1a2c3d4e5f5b" /> <span id="b1a2c3d4e5f5a" /> 为转写结果标注说话人编号，用于区分会议、访谈中的发言人。qwen-audio-3.1-asr-flash 和 qwen-audio-3.1-asr-flash-filetrans 支持该能力。

- **时间戳**：<span id="asr-timestamps" /> 将句子或字词与音频位置对应，用于字幕对齐、关键词高亮和音频跳转。

- **敏感词过滤**：<span id="asr-sensitive-filter" /> 将指定词汇替换为星号或从转写文本中移除。

音频准备、连接与并发管理、异步作业及异常处理，参见[语音识别最佳实践](/zh/model-studio/speech-recognition-best-practices)。
