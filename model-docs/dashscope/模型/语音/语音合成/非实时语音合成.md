# 非实时语音合成

> 通过 HTTP 将完整文本转换为语音，了解模型特性、快速调用方法和合成效果优化方式。

<meta property="og:title" content="非实时语音合成" />

## 功能介绍 <span id="a5e9de808eli8" />

非实时语音合成通过 HTTP 一次提交完整文本，支持非流式和 SSE 流式输出。非流式在合成完成后返回完整音频，流式逐段返回音频数据。

<span id="37914114aaidw" />

<span id="783e508579rco" />

- **多语言与方言**：根据目标语言选择模型和音色，也可通过指令指定方言。参见[方言](/zh/model-studio/non-realtime-tts-user-guide#8a7604d333kut)。
- **表现力控制**：通过自然语言指令调整语速、情感等表达，或在文本中插入情感与富语言标签。参见[指令控制](/zh/model-studio/non-realtime-tts-user-guide#nrt_instruct_h3)和[情感与富语言标签](/zh/model-studio/non-realtime-tts-user-guide#nrt_emtag_h3)。
- **自定义音色**：通过[音色复刻](/zh/model-studio/voice-cloning-user-guide)从音频样本创建音色，或通过[音色设计](/zh/model-studio/voice-design-user-guide)使用文字描述创建音色。
- **精细控制与公式朗读**：使用 [SSML 与 LaTeX](/zh/model-studio/ssml-latex-user-guide)控制停顿、发音等效果，或将公式转换为语音。
- **Markdown 过滤**：将包含表格等结构的 Markdown 文本转换成适合朗读的内容。参见[Markdown 过滤](/zh/model-studio/non-realtime-tts-user-guide#tts_markdown_filter)。

<Note>
  * 各模型及音色支持的能力有所不同，使用前请核对对应功能的支持范围。
  * 需要分批输入文本时，请使用[实时语音合成](/zh/model-studio/realtime-tts-user-guide)。
</Note>

## 开始使用 <span id="e79cb56cfdbbp" />

<span id="nrt00_prereq_h2" />

在控制台[获取 API Key](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key)，并将其配置到环境变量 `DASHSCOPE_API_KEY`。

安装示例依赖：

```bash
pip install requests
```

<Tabs>
  <Tab title="Qwen-Audio-TTS（推荐）">
    以下使用华北2（北京）地域的 qwen-audio-3.1-tts-flash 和系统音色 `longanhuan_v3.1`，演示非流式和流式输出。

    <Tabs>
      <Tab title="非流式输出">
        ```python title="Python" height="400" expandable
        import os
        import requests

        response = requests.post(
            'https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/audio/tts/SpeechSynthesizer',
            headers={"Authorization": f"Bearer {os.environ['DASHSCOPE_API_KEY']}"},
            json={
                "model": "qwen-audio-3.1-tts-flash",
                "input": {
                    "text": "你好，欢迎使用阿里云百炼。",
                    "voice": "longanhuan_v3.1",
                    "format": "wav",
                    "sample_rate": 24000
                }
            },
            timeout=60,
        )
        response.raise_for_status()
        audio_url = response.json()["output"]["audio"]["url"]
        audio_response = requests.get(audio_url, timeout=60)
        audio_response.raise_for_status()
        with open("output.wav", "wb") as f:
            f.write(audio_response.content)
        ```

        运行后，音频保存在当前目录的 `output.wav` 文件中。
      </Tab>

      <Tab title="流式输出">
        以下示例逐行打印 SSE 返回事件。事件中的 `output.audio.data` 为 Base64 编码的音频片段。

        ```python title="Python" height="400" expandable

        import requests

            'https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/audio/tts/SpeechSynthesizer',
            headers={"Authorization": f"Bearer {os.environ['DASHSCOPE_API_KEY']}", "X-DashScope-SSE": "enable"},
            json={
                "model": "qwen-audio-3.1-tts-flash",
                "input": {
                    "text": "你好，欢迎使用阿里云百炼。",
                    "voice": "longanhuan_v3.1",

                    "sample_rate": 24000
                }
            },
            stream=True,
            timeout=60,
        )
        response.raise_for_status()
        for line in response.iter_lines():
            print(line.decode("utf-8"))
        response.close()
        ```

## 合成效果优化 <span id="12884a10929p9" />

### 语言与发音

数字、缩写或符号的读法不符合预期时，可通过 `language_hints` 指定合成目标语言。参数配置请参见 [Qwen-Audio-TTS API](/zh/model-studio/qwen-audio-tts-http-api) 或 [CosyVoice API](/zh/model-studio/cosyvoice-tts-http-api)。使用 Qwen-Audio-TTS 时，还可通过 `hot_fix` 指定词语的发音，或在合成前替换词语。

需要控制停顿、数字读法或字词发音时，可使用 SSML。Qwen-Audio-TTS 和 CosyVoice 的适用模型、音色、接口与标签用法，请参见 [SSML 与 LaTeX](/zh/model-studio/ssml-latex-user-guide)。

### Markdown 过滤 <span id="tts_markdown_filter" />

合成包含表格、链接等 Markdown 格式的内容时，可将 `enable_markdown_filter` 设为 `true`，让服务先将 Markdown 转换成适合朗读的文本。Qwen-Audio-TTS 和 CosyVoice 支持此功能，cosyvoice-v2 除外。配置方法参见 [Qwen-Audio-TTS API](/zh/model-studio/qwen-audio-tts-http-api) 和 [CosyVoice API](/zh/model-studio/cosyvoice-tts-http-api)。

### 指令控制 <span id="nrt_instruct_h3" />

在请求的 `input` 中增加 `instruction`，用自然语言说明要合成的语种，描述语速、情感或说话方式，控制合成语音的表现。

<Note>
  如需创建具有特定性别、年龄或音色特质的新音色，或参考声音描述的编写建议与示例，请参见[音色设计](/zh/model-studio/voice-design-user-guide)。
</Note>

<Tabs>
  <Tab title="Qwen-Audio-TTS">
    qwen-audio-3.1-tts-plus、qwen-audio-3.1-tts-flash、qwen-audio-3.0-tts-plus、qwen-audio-3.0-tts-flash 的系统音色、复刻音色和设计音色均支持在合成请求中通过 `instruction` 设置自然语言指令。

    建议在 `instruction` 中说明合成语种和所需效果，以提升合成质量。指令中指定的语种须与待合成文本的语种一致。例如，合成荷兰语文本时，可设置：


### 方言 <span id="8a7604d333kut" />

通过方言功能，可将文本合成为河南话、四川话等中文方言语音。方言的选择方式取决于模型和音色类型。

<Tabs>
  <Tab title="Qwen-Audio-TTS">
    - **系统音色**：从 [Qwen-Audio-TTS 音色列表](/zh/model-studio/qwen-audio-tts-voice-list)中选择支持目标方言的音色。直接支持该方言的音色无需额外设置；支持方言指令的音色使用指令控制参数 `instruction` 指定。

      <Note>
        使用 qwen-audio-3.1-tts-flash 的多语种与方言音色时，也可通过 `language_hints` 指定方言，参见[多语种与方言音色的设置方法](/zh/model-studio/qwen-audio-tts-voice-list#qwen-tts31-language-hints)。
      </Note>

    - **复刻音色**：通过指令控制参数 `instruction` 指定方言。

    - **设计音色**：暂不支持方言。

    对于支持方言指令的音色，在请求的 `input` 中设置 `instruction="请讲上海话。"`，可将中文文本合成为上海话。
  </Tab>

  <Tab title="CosyVoice">
    - **系统音色**：选择直接支持目标方言的音色，例如 `longshange_v3`；或选择支持方言指令的音色，例如 `longanhuan_v3`，按[音色列表](/zh/model-studio/cosyvoice-voice-list)的格式填写指令。
    - **复刻音色**：使用支持指令控制的模型，通过 `instruction` 指定方言。
    - **设计音色**：暂不支持方言。

    <Note>
      cosyvoice-v3-plus 的复刻音色不支持通过指令指定方言。
    </Note>

    使用 CosyVoice 的开始使用示例时，将 `input` 替换为以下内容，可使用 `longanhuan_v3` 输出河南话：

    ```json
    {
      "text": "叫你去买盐，你买回来一袋面，这不是弄啥嘞吗！",
      "voice": "longanhuan_v3",
      "format": "wav",
      "sample_rate": 24000,
      "instruction": "请用河南话表达。"
    }
    ```
  </Tab>
</Tabs>

Qwen3-TTS 使用支持目标方言的系统音色，参见 [Qwen3-TTS 音色列表](/zh/model-studio/qwen-tts-voice-list)。

### 情感与富语言标签 <span id="nrt_emtag_h3" />

<Note>
  适用于 qwen-audio-3.1-tts-plus、qwen-audio-3.1-tts-flash、qwen-audio-3.0-tts-plus 和 qwen-audio-3.0-tts-flash。
</Note>

情感与富语言标签可控制语音的情感和风格，并在指定位置加入笑声、叹息等拟声效果。将标签直接写入待合成文本 `text`，无需额外参数。

#### 使用示例

以下文本先使用兴奋语气，在指定位置插入笑声后继续合成正文：

```text
[excited]今天的天气真不错！[laughing]我们一起出去玩吧！
```

以下文本在第二句切换为兴奋语气：

```text
[serious]请注意安全事项。[excited]好了，现在让我们开始吧！
```
