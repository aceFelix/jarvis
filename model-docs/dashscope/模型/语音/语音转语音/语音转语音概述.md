## S2S（Speech-to-Speech）与Pipeline对比 <span id="d1a2c3d4e5f02" />

构建语音应用有两种方式：

<table style={{ display: "table", tableLayout: "fixed", width: "100%", overflowWrap: "anywhere" }}><colgroup><col style={{ width: "24.964739%" }} /><col style={{ width: "37.51763%" }} /><col style={{ width: "37.51763%" }} /></colgroup><thead><tr><th style={{ verticalAlign: "top" }}><p /></th><th style={{ verticalAlign: "top" }}><p><strong>S2S</strong></p></th><th style={{ verticalAlign: "top" }}><p><strong>Pipeline（ASR + LLM + TTS）</strong></p></th></tr></thead><tbody><tr><td style={{ verticalAlign: "top" }}><p>延迟</p></td><td style={{ verticalAlign: "top" }}><p>低 -- 单模型流式处理</p></td><td style={{ verticalAlign: "top" }}><p>较高 -- 3个阶段串行处理</p></td></tr><tr><td style={{ verticalAlign: "top" }}><p>音频理解</p></td><td style={{ verticalAlign: "top" }}><p>端到端 -- 能感知语调、情绪并做出相应回应</p></td><td style={{ verticalAlign: "top" }}><p>先转文本再处理 -- 音频中的细微信息丢失</p></td></tr></tbody></table>

- <strong>使用S2S</strong>：当交互式对话、低延迟和音频感知的回复是关键需求时。
- <strong>使用Pipeline</strong>：当需要为每个阶段分别选择最优的ASR、LLM和TTS模型时。

本文档继续介绍 S2S 单模型路线（Omni、Qwen-Audio Realtime、Livetranslate）。如选择 Pipeline 路线，分别在以下文档中挑选三个组件：

- <strong>ASR（语音识别）</strong>：[语音识别](/zh/model-studio/asr-model)
- <strong>LLM（大语言模型）</strong>：[文本生成](/zh/model-studio/text-generation-model)
- <strong>TTS（语音合成）</strong>：[语音合成](/zh/model-studio/tts-model)

## 实时还是文件模式？ <span id="d1a2c3d4e5f29" />

- <strong>实时</strong>：适用于语音助手、呼叫中心、同声传译等实时语音交互场景。音频流式输入，语音流式输出。

<Note>
  Realtime API 提供 WebSocket、WebRTC 和 AOQ 三种接入方式，各型号支持范围和协议选型见 [Realtime API 概述](/zh/model-studio/realtime-api-overview)。
</Note>

- <strong>文件模式（HTTP）</strong>：可以用延迟换取更好的效果，适用于视频配音、播客翻译、离线内容处理等场景。文件模式下还支持 Function Calling、联网搜索、思考模式、视频上下文等附带能力（详见下方“S2S 单模型的附带能力”）。

## S2S 单模型的附带能力 <span id="s2sextra_parent_h2" />

以下介绍语音交互中的工具调用、联网搜索及文本推理能力。

### Function Calling <span id="d1a2c3d4e5f30" />

根据音视频内容查询知识库、查询日程或触发工作流，可使用 Qwen3.8-Omni-Flash-Realtime、Qwen-Audio Realtime。Qwen-Audio-Live 可在语音对话中[调用函数](/zh/model-studio/qwen-audio-live#live-function-calling)。

### 联网搜索 <span id="b3c4d5e6f7002" />

需要检索实时信息并生成语音回复时，实时对话可使用 Qwen3.8-Omni-Flash-Realtime 或 Qwen3.5-Omni-Realtime；文件调用可使用 Qwen3.5-Omni（Chat Completions，Plus 和 Flash 系列）。模型自主决定是否搜索。Qwen-Audio Realtime 3.1 Plus/Flash 和 3.0 Plus/Flash 也支持联网搜索，通过 `enable_search` 开启。这四个 Qwen-Audio Realtime 型号均可在同一会话中启用联网搜索和 Function Calling。

<Note>
  Qwen3-Omni-Flash 和 Livetranslate 模型不支持此功能。
</Note>

### 思考模式 <span id="d1a2c3d4e5f33" />

<Note>
  Qwen3-Omni-Flash 在思考模式下不支持生成语音。
</Note>

## 翻译 <span id="d1a2c3d4e5f36" />

以下模型系列均支持语音翻译：

- <strong>Qwen3.8-Livetranslate</strong>：支持 60 种源语言和 29 种语言的语音输出，支持音频与图像输入。详见[模型信息](/zh/model-studio/qwen3-8-livetranslate-flash-realtime)。
- <strong>Qwen3.5-Livetranslate</strong>：支持 60 种语言互译，其中 29 种支持音频+文本输出、31 种仅支持文本输出，覆盖中文、英语、法语、德语、俄语、日语、韩语、西班牙语、葡萄牙语、阿拉伯语等主流语种。
- <strong>Qwen3-Livetranslate</strong>：支持18种语言 + 5种中文方言，约3秒延迟，开箱即用。文件模式支持输入视频以获得上下文感知的翻译精度。其中7种语言仅输出文本（不输出语音）。
- <strong>Qwen3.8-Omni-Flash-Realtime</strong>：支持实时语音翻译，语音生成语种与 Qwen3.5-Omni-Realtime 一致，支持36种语种和方言，各音色支持范围见[音色列表](/zh/model-studio/omni-voice-list#qwen38-voices)。
- <strong>Qwen3.5-Omni</strong>：支持29种输出语言 + 7种中文方言。优秀的音视频理解能力和联网搜索。可通过系统提示词注入术语和领域上下文。支持实时和文件模式。
- <strong>Qwen3-Omni-Flash</strong>：支持11种输出语言 + 8种中文方言。可通过系统提示词注入术语和领域上下文。支持实时和文件模式。

<Note>
  快速搭建翻译应用可选择 Livetranslate；需要离线语音输出、联网搜索和术语注入时，可选择 Qwen3.5-Omni。
</Note>
