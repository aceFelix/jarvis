# 音色列表

> Qwen-Omni 和 Qwen-LiveTranslate 模型支持的音色、试听、voice 参数值及语言范围。

## Omni 音色

### 模型与默认音色

- <span id="qwen38-voices" />**Qwen3.8-Omni 系列**：`qwen3.8-omni-flash-realtime`；默认音色：`Tina`。

- <span id="afe9cac84a4q0" />**Qwen3.5-Omni 系列**：Qwen3.5-Omni、Qwen3.5-Omni-Realtime 系列（`qwen3.5-omni-plus`、`qwen3.5-omni-flash`、`qwen3.5-omni-plus-realtime`、`qwen3.5-omni-flash-realtime`）；默认音色：`Tina`。

- <span id="773cc75ab7j98" />**Qwen3-Omni 系列**：`qwen3-omni-flash`、`qwen3-omni-flash-realtime-2025-09-15`；默认音色：`Cherry`。

Qwen3.8-Omni-Flash-Realtime 支持 36 种语种和方言的语音生成，与 Qwen3.5-Omni-Realtime 一致；模型整体范围见[语音生成语言](/zh/model-studio/qwen-omni#d54e85c641oux)。各音色的具体范围见下表。

通过 `session.audio.output.voice` 设置 Qwen3.8-Omni-Flash-Realtime 音色，详见[音色配置](/zh/model-studio/client-events#session-audio-voice)；自定义音色参见[声音复刻](/zh/model-studio/qwen-omni-voice-cloning-user-guide)。

系统音色与声音复刻支持的方言范围不同。复刻前请查看[声音复刻的语言要求](/zh/model-studio/qwen-omni-voice-cloning-user-guide#fe3daa6c3f7jw)。
